FraudStream Architecture

Real-time fraud detection pipeline — Kafka → PyFlink → Rule Engine → Iceberg → Streamlit

Data Pipeline

  • • Kafka KRaft (no ZooKeeper) with Avro serialization
  • • PyFlink 2.x DataStream API with RocksDB state
  • • GeoIP enrichment (MaxMind embedded reader)
  • • Velocity windows via MapState minute buckets
  • • Device fingerprint correlation
  • • Incremental checkpointing for fault tolerance

Fraud Detection

  • • YAML-driven hot-configurable rule engine
  • • Velocity, geo-anomaly, and amount rules
  • • ML scoring with circuit breaker pattern
  • • Feast feature store (3ms timeout SLA)
  • • Dual sink: Kafka alerts + PostgreSQL
  • • Dead Letter Queue for failed events

Analytics & Storage

  • • Apache Iceberg on MinIO (append-only tables)
  • • PyIceberg → Arrow → DuckDB query pattern
  • • Streamlit dashboard (6 pages + Home)
  • • Kafka consumer daemon (analytics.dashboard)
  • • Prometheus + Grafana + Alertmanager
  • • Management API for model version control
